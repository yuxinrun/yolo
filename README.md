# YOLO · 人生只有一次

> 人生只有一次，不必活成标准答案。

一个纯前端静态站点，记录关于幸福、自洽、取舍、遗憾与自由的思考。

这里的 YOLO 不是享乐放纵，而是明白人生仅此一次，想清楚如何不白活、如何找到属于自己的幸福，从外界标准、内耗与世俗成功学里慢慢抽身。没有广告、没有会员、没有付费引导，只是一个安静的阅读空间。

## 快速开始

无需构建、无需安装依赖。

```bash
# 方式一：直接双击 index.html

# 方式二：起一个本地静态服务（推荐，便于模拟线上环境）
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

首次打开需要联网：Tailwind CSS v3、Font Awesome 6、Inter / 思源黑体走 CDN。断网时中文字体会自动回落到系统字体（PingFang SC / 思源黑体 / 微软雅黑）。

## 内容管理

所有写法在 `js/data.js` 文件头也有注释说明。

### 新增一篇文章

在 `ARTICLES` 数组里复制任意一项：

```js
{
  id: 'life-07',              // 唯一，不可重复
  category: 'life',           // 必须是 CATEGORIES 里已有的 id
  title: '标题',
  excerpt: '卡片上的简短摘要',
  tags: ['时间观', '自由'],    // 同时用于话题归集
  date: '2026-11-20',
  minutes: 5,
  content: [
    { type: 'p',     text: '普通段落，可以用 **重点** 标记强调。' },
    { type: 'p',     text: '> 以 "> " 开头的段落会自动渲染成引用框高亮。' },
    { type: 'quote', text: '也可以显式写成引用框。' },
    { type: 'h2',    text: '小标题' },
    { type: 'list',  items: ['一条', '两条'] }
  ]
}
```

支持的块类型：`p`、`quote`、`h2`、`list`；段落、列表、引用里都可以用 `**文字**` 做强调。所有文本都会做 HTML 转义，引号和符号可以放心写。

### 新增一句语录

在 `QUOTES` 里复制一项，改 `id`（唯一）、`text`、`tags`。`tags` 同时参与语录集搜索与话题归集。

```js
{ id: 'q94', text: '「一句独立的话。」', tags: ['幸福', '当下'] }
```

### 新增一个话题

在 `TOPICS` 里加一项：`match` 是匹配词数组（关联文章，命中标题 / 摘要 / 标签任意一个即归入），`search` 是单个词（关联语录，点击「查看全部」时自动填入语录集搜索框）。话题按钮、相关文章列表、相关语录列表全部自动生成。

```js
{ id: 't17', name: '新的话题', note: '一句话说明', match: ['关键词'], search: '关键词' }
```

给文章 / 语录的 `tags` 带上相同词，它们就会自动归到这个话题下。

### 新增一个分类

在 `CATEGORIES` 里加一项（`id` / `name` / `en` / `desc` / `icon`），顶部导航、移动端菜单、页面版块、页脚链接会自动生成；再把文章的 `category` 填成新 id 即可。空版块有兜底文案。

### 修改首页入口与固定文案

- 首页 6 个入口：`data.js` 的 `ENTRIES`。`target` 填版块 id，可选 `keyword` 会在跳转语录集时自动搜索。
- Hero 标题、副标题、置顶核心语录、站点简介、话题索引标题、语录集标题、页脚 slogan：都在 `index.html` 里，已用「可编辑文案」注释标出。

## 功能说明

- **单页平滑滚动**：`scroll-behavior: smooth`，固定导航带锚点偏移。
- **文章阅读**：点击卡片进入纯阅读视图，支持浏览器前进 / 后退与「返回原栏目」，无评论系统。
- **语录集**：CSS columns 流式布局（PC 多列、手机单列）、关键词搜索、只看收藏、随机一句、复制句子。
- **随机语录弹窗**：居中淡入淡出，带站点署名，适合截图分享；可换一句、复制、收藏。
- **收藏与暗色模式**：均保存在浏览器 `localStorage`，不需要后端。
- **移动端**：固定导航自动折叠为汉堡菜单。

### 本地存储键

| 键 | 内容 |
| --- | --- |
| `yolo:favorites:v1` | 收藏的语录 id 数组 |
| `yolo:theme:v1` | `light` / `dark`；首次访问跟随系统偏好 |

### 路由约定

| URL hash | 行为 |
| --- | --- |
| `#home` / `#life` / `#happiness` / `#inertia` / `#boundary` / `#farewell` / `#quotes` | 平滑滚动到对应版块 |
| `#/article/{文章id}` | 打开纯阅读视图 |

复制语录时默认附带站点署名，不需要可把 `js/app.js` 顶部的 `COPY_SIGNATURE` 改为空字符串 `''`。

## 设计规范

配色为低饱和、护眼的纸质随笔质感，日间 / 夜间两套，统一定义在 `tailwind.config`（`index.html` 内联）与 `css/style.css` 的 CSS 变量中。

| 用途 | 日间 | 夜间 |
| --- | --- | --- |
| 主背景 | `#F7F4F0` | `#1C1B19` |
| 卡片 | `#FFFFFF` | `#252421` |
| 语录卡浅米色 | `#F1ECE5` | `#2B2926` |
| 正文 | `#383532` | `#E4DFD8` |
| 次要文字 | `#726E69` | `#A29C93` |
| 主强调 | `#8C6A58` | `#C2A38D` |
| 辅助（灰蓝） | `#63747B` | `#8FA5AE` |
| 分割线 | `#E2DDD7` | `#3A3732` |

- 中文：思源黑体 / PingFang SC / Noto Sans SC；英文：Inter。正文行高 1.8，标题行高 1.3，引用句放大字号并略拉字距。
- 动画克制缓慢：卡片 `shadow-sm` → hover `shadow-md` 并轻微上浮，弹窗淡入淡出，尊重 `prefers-reduced-motion`。
- 图标使用 Font Awesome 6 免费版（regular / solid + 小字号低透明度实现细线观感）。若有 Font Awesome Pro，把图标类换成 `fa-light` 可获得更细的线稿风格。

## 技术栈与依赖

| 依赖 | 版本 / 说明 |
| --- | --- |
| Tailwind CSS | v3 Play CDN，`darkMode: 'class'`，配置内联于 `index.html` |
| Font Awesome | 6.5.2，cdnjs |
| Google Fonts | Inter、Noto Sans SC |
| JavaScript | 原生 ES5+ 语法，无框架、无构建、无模块化（可直接 `file://` 打开） |

Play CDN 适合个人静态站，但会在控制台提示非生产用途。若要完全离线或上生产环境，建议本地编译 Tailwind 并把 `index.html` 中的 CDN 脚本替换为编译产物。
